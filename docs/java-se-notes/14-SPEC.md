# Spec：第 14 模块 Lambda、函数式接口与方法引用

GitHub spec：[#12](https://github.com/Q1Xuan/java-se/issues/12)。

## 问题与目标

已学过 Java 的读者需要复习第 14 模块，但课程内容分散在字幕、课件和练习中。整理一份中文知识清单，按知识主题准确覆盖本模块全部 13 节，方便查找规则、理解例子并再次使用。

## 读者需求

1. 理解 Lambda 的用途、表达式与代码块语法、参数、返回值及目标类型。
2. 理解函数式接口及自定义接口，并联系匿名类理解适用场景。
3. 复习课程涉及的 `Consumer`、`Predicate`、`Function`、`Supplier` 和相关用法。
4. 从课程练习中理解 Lambda 在数组、列表和操作中的实际应用。
5. 识别课程中的方法引用形式，理解参数匹配、绑定接收者与未绑定接收者。
6. 理解函数式接口的组合方法、执行顺序及课程涉及的比较器组合与排序。
7. 对课程涉及的集合操作及其他知识获得足够讲解，不因其他模块也会讲到而省略。
8. 通过紧邻规则的简短示例、必要的图或对比，理解正确写法和常见错误。
9. 知道资料是否实际读到、示例如何验证，以及任何缺失资料的影响。

- 逐项读取并核对第 1—13 节可获得的字幕、课件、练习及其他资料；按知识主题组织，不逐节复述。旧笔记只作线索，下载链接不等于已读取源码。课件中的图片代码与表格也要检查。
