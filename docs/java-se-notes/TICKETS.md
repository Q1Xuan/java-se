第 13 模块通过后，从 01 开始按顺序推进，跳过已完成的 13。每次开始一个模块，再根据其实际资料生成三个任务：

| 任务 ID | 内容 | 交付 |
| --- | --- | --- |
| `TNN-01` | 资料核对 | 资料覆盖记录、疑问和缺失项 |
| `TNN-02` | 知识点整理 | 模块笔记及必要短代码 |
| `TNN-03` | 检查与收尾 | 检查结果、修订笔记、更新进度 |

其中 `NN` 替换为模块编号。任务验收沿用 spec，结合本模块的真实内容补充，不机械复制第 13 模块的资料数量或主题。

## 每次 session 收尾

1. 更新当前 ticket 状态及已满足的验收项。
2. 在进度记录中写明已处理资料、剩余资料和准确的停留位置。
3. 保存已核对的结论及来源，列出尚未解决的问题。
4. 写清下一个可执行动作；没有完成的任务保留真实状态。

当前 ticket 没完成时，下次继续该 ticket，不重新开始，也不自动越过依赖。
