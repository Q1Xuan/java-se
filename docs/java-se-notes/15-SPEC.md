# Spec：第 15 模块 Java 集合框架、List、Set 与 Map

GitHub spec：[#19](https://github.com/Q1Xuan/java-se/issues/19)。

## 问题与目标

已学过 Java 的读者需要复习集合框架，但本模块的知识分散在 29 节课程和多个练习中。整理一份按知识主题组织的中文知识清单，覆盖实际读到的课程内容，帮助读者查找规则、理解区别并使用相关 API。

## 读者需求

1. 理解集合框架的主要接口、实现及其关系，掌握课程涉及的列表和集合工具方法。
2. 理解哈希码、相等性及其与哈希集合和映射的关系。
3. 复习 Set 的基本操作、集合运算、有序集合、导航和范围操作。
4. 复习 Map 的基本和更新操作、集合视图、有序映射及导航方法。
5. 理解课程涉及的枚举集合及使用场景。
6. 从纸牌、任务、座位、冒险游戏和库存练习中掌握相关知识，而不必阅读完整业务程序。
7. 对资料涉及的知识获得充分讲解，即使其他模块也涉及相同内容；用必要短例、图或对比解释规则和错误。
8. 知道资料实际读取情况、检查结果和缺失资料的影响。

## 范围和写作决定

- 逐项核对第 1—29 节可获得的字幕、课件、练习、源码及其他资料，按知识主题组织，实施时以原资料实际内容为准，发现额外知识点也须处理并记录。现有文件名和旧笔记只能作为线索，下载链接不等于已读取源码；课件中的图片代码与表格也要检查。
- 初步范围包括集合框架和 Collections（1—8 节）、哈希和 Set（9—18 节）、Map 和枚举集合（19—26 节）、综合练习（27—29 节）。这只是依据课程标题的初步划分，不代表资料已读或知识覆盖已确认。
- 沿用第 13 模块已确认的风格：面向学后复习，用简洁中文先给出规则；分类按需用图，规则紧邻短代码或具体示例，说明错误原因，避免无意义的重复和文字堆砌。资料涉及的内容应讲清，不能因为其他模块也涉及而省略。
- 练习提炼知识点，不复制完整业务程序；不扩展成脱离课程范围的系统教程。
- 核实课程使用的 JDK 版本及实际验证环境；版本差异、资料冲突或可疑规则以对应官方资料核对并记录依据，不将推测写成事实。
- 新笔记、覆盖记录和进度记录保存在现有项目；原始课件、字幕、源码下载链接和旧笔记留在本地，不收入公开项目。
- 用户指定优先处理第 15 模块，这调整总 spec 中的执行顺序，不改变课程编号。

## 验收与检查

- 知识清单覆盖 29 节实际读到的知识点及相关练习；逐项覆盖记录指出对应位置、未收入内容及原因、无法读取资料及影响。未取得资料不得声称已经核对。

- 针对集合操作、哈希与相等性、排序、视图和导航等关键规则核对；有疑问时查相应版本的官方规范或 API 并记录依据。
- 检查中文表达、代码围栏、相对链接、重复内容及公开文件范围；不为纯文字强建测试框架。
- 更新任务状态和接续记录，标明已完成事项、剩余问题和下一步。
